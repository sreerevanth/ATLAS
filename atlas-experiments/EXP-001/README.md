# EXP-001: Topological Signature Benchmark

This experiment evaluates which topological representation is most suitable for the Topology Interchange Protocol (TIP).

## Research Question
Which representation provides the best combination of locality preservation, robustness to noise, stable hashing, privacy preservation, and computational efficiency?

## Candidate representations:
* Persistence Landscape
* Persistence Image
* Betti Curve
* Persistence Entropy
